# 모드와 진행 구조

**상태: 5단계 구현 완료, 6단계 제안.** (2026-07-31)

경기가 재미있어진 뒤에 얹는다. 순서를 뒤집으면 재미없는 경기를 여러 번
하게 만드는 구조가 된다.

## 모드

| 모드 | 내용 |
|---|---|
| 빠른 경기 | 현재의 1P/2P 단판. 유지 |
| 토너먼트 | **구현.** 8팀 녹아웃 3라운드, 무승부 승부차기 |
| 리그 | 8팀 풀리그 14경기, 승점 순위표 |
| 시즌 | 리그 + 컵. 여러 시즌 누적 |

**토너먼트를 먼저 만든다.** 짧고(3경기), 승부차기라는 새 재미가 붙고,
리그·시즌의 뼈대(대진·기록·저장)를 그대로 재사용할 수 있다.

## 승부차기

녹아웃의 전제인 별도 미니 상태 기계로 구현했다.

- 5번씩, 동률이면 서든데스
- 왼쪽/가운데/오른쪽을 선택한다
- 팀 슛·선방 능력치와 골키퍼 방향 일치 여부로 성공을 판정한다

전체 필드 물리를 재사용하는 제안은 대기 시간이 길어 아케이드 원칙과
충돌했다. 방향 선택을 한 번에 판정하는 짧은 방식으로 확정했다.

```
pk {
  turn,          // 0 | 1
  shot,          // 각 팀 시도 횟수
  scored: [n, n],
  sudden         // 서든데스 진입 여부
}
```

## 저장

`localStorage`를 단일 v2 키로 정리했다.

```
ilbbang.soccer11.v2 = {
  version: 2,
  settings: { level, matchSec, teams, formation, tactics },
  records:  { [level]: {w, d, l, bestGd} },
  progress: { mode, round, fixtures[], table[], … } | null
}
```

단일 키 + `version` 필드로 바꾼다.

마이그레이션 함수가 v1 난이도별 전적을 `records`로 가져온다.
플레이어의 기록을 날리지 않는다. v1 키는 마이그레이션 후에도 한동안
지우지 않는다 (롤백 여지).

v1 키는 삭제하지 않는다. 모든 접근은 `try/catch`로 감싼다.

## 기록

경기 후 요약 화면.

| 항목 | 구현 |
|---|---|
| 점유율 | `ball.owner` 의 팀별 누적 시간 |
| 슈팅 / 유효슈팅 | 슛 액션 수 / 골문 방향 도달 수 |
| 코너 | 세트피스 카운트 |
| 파울 / 카드 | 판정 카운트 |

대부분 이미 있는 이벤트를 세기만 하면 된다. 점유율만
`input-system.md` 의 공 소유 상태에 의존한다.

## 팀 선택 화면

토너먼트·리그에 필요하다. 팀 8~12개를 등급 막대와 함께 보여준다
(`team-tactics.md` — 숫자 대신 5단계 막대).

## 런처 연결

`/index.html` 런처의 플레이 버튼이 이미 `games/soccer/` 를 가리킨다.
모드가 늘어도 진입점은 하나로 유지한다 — 런처 번들은 외부 도구가
재생성하므로 건드리지 않는 편이 안전하다 (`principles.md` 1번).

## 5단계 검증

- 대진은 사용자 팀 제외, 3팀 중복 없음: 셀프테스트 통과.
- 승부차기 5회 조기 종료·서든데스: 셀프테스트 통과.
- 브라우저 새로고침 후 같은 1라운드 대진 복원 확인.
- v1 `7승 2무 3패, +4`가 v2로 보존됨.
- 저장 쓰기가 실패해도 예외를 삼키며 게임은 계속된다.

## 6단계 검증 기준

- 리그 14경기 일정과 순위 동률 규칙이 결정론 검사에 들어간다.
- 시즌은 리그와 컵을 마치고 다음 시즌으로 넘어간다.
- 경기 종료 화면에 핵심 기록이 표시된다.
