# 모드와 진행 구조

**상태: 전부 제안.** 미측정.

경기가 재미있어진 뒤에 얹는다. 순서를 뒤집으면 재미없는 경기를 여러 번
하게 만드는 구조가 된다.

## 모드

| 모드 | 내용 |
|---|---|
| 빠른 경기 | 현재의 1P/2P 단판. 유지 |
| 토너먼트 | 8팀 녹아웃 3라운드. 무승부 시 승부차기 |
| 리그 | 8팀 풀리그 14경기, 승점 순위표 |
| 시즌 | 리그 + 컵. 여러 시즌 누적 |

**토너먼트를 먼저 만든다.** 짧고(3경기), 승부차기라는 새 재미가 붙고,
리그·시즌의 뼈대(대진·기록·저장)를 그대로 재사용할 수 있다.

## 승부차기

녹아웃의 전제. 별도의 미니 상태 기계다.

- 5번씩, 동률이면 서든데스
- 기존 물리를 그대로 쓴다
- 필요한 것은 조준(`input-system.md`)과 골키퍼 방향 선택뿐

분량 대비 재미가 가장 큰 항목이다.

```
pk {
  turn,          // 0 | 1
  shot,          // 각 팀 시도 횟수
  scored: [n, n],
  sudden         // 서든데스 진입 여부
}
```

## 저장

`localStorage` 키를 정리한다. 현재 `ilbbang.soccer11.v1.rec{n}` 과
`.lvl` 두 종류가 흩어져 있다.

```
ilbbang.soccer11.v2 = {
  version: 2,
  settings: { level, matchLen, offside, team },
  records:  { [level]: {w, d, l, bestGd} },
  progress: { mode, round, fixtures[], table[], … } | null
}
```

단일 키 + `version` 필드로 바꾼다.

**마이그레이션 함수를 둔다.** v1 의 난이도별 전적을 `records` 로 가져온다 —
플레이어의 기록을 날리지 않는다. v1 키는 마이그레이션 후에도 한동안
지우지 않는다 (롤백 여지).

`localStorage` 접근은 현재처럼 전부 `try/catch` 로 감싼다. 사파리
프라이빗 모드에서 던진다.

## 기록

경기 후 요약 화면.

| 항목 | 구현 |
|---|---|
| 점유율 | `ball.owner` 의 팀별 누적 시간 |
| 슈팅 / 유효슈팅 | 슛 액션 수 / 골문 방향 도달 수 |
| 코너 | 세트피스 카운트 |
| 파울 / 카드 | 판정 카운트 |

대부분 이미 있는 이벤트를 세기만 하면 된다. 점유율만
`input-system.md` 의 공 소유 상태에 의존한다.

## 팀 선택 화면

토너먼트·리그에 필요하다. 팀 8~12개를 등급 막대와 함께 보여준다
(`team-tactics.md` — 숫자 대신 5단계 막대).

## 런처 연결

`/index.html` 런처의 플레이 버튼이 이미 `games/soccer/` 를 가리킨다.
모드가 늘어도 진입점은 하나로 유지한다 — 런처 번들은 외부 도구가
재생성하므로 건드리지 않는 편이 안전하다 (`principles.md` 1번).

## 검증 기준

- 토너먼트 3라운드를 완주할 수 있다.
- 승부차기가 서든데스까지 정상 동작한다.
- 저장 후 브라우저를 닫았다 열면 진행 상황이 복원된다.
- v1 전적이 있는 상태에서 v2 로 마이그레이션되고 기록이 보존된다.
- `localStorage` 가 막힌 환경에서도 게임이 동작한다 (진행 저장만 실패).
