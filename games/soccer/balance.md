# 밸런스 측정

**상태: 측정됨** (2026-07-31). 추측이 아니라 실행 결과다.
측정 도구는 `tools/soccer-sim.js`.

## 측정 조건

조건이 바뀌면 숫자를 비교할 수 없다. 항상 함께 기록한다.

```
명령      node tools/soccer-sim.js -n 200 --seed 1
경기 수   난이도당 200
시드      1 (mulberry32, 고정)
봇        사람 자리에 aiPlayer + LEVELS[1](보통), isChaser=true
경기 길이 180초
화면      1280×720 가로 (회전 없음 — 물리에는 영향 없음)
소요      난이도당 약 3분
```

## 결과

|---|---|---|---|---|---|---|---|---|

세 난이도와 총 득점이 모두 목표 안에 있다. **현재 밸런스는 맞다.**

## 해석

### 쉬움 목표를 73% → 80% 로 고쳤다

측정 당시 목표는 73% 였고 실측 81.5% 는 그 신뢰구간 밖이었다.
2026-07-31 사용자 결정으로 **실측값을 목표로 인정**했다.

근거 두 가지.

- 봇은 사람의 하한이다(아래 참조). 사람은 81.5% 보다 더 이긴다.
  73% 로 맞추면 사람이 체감하는 쉬움은 오히려 어려워진다.
- 쉬움은 처음 잡는 사람이 이기라고 있는 난이도다.

80% 는 신뢰구간(75.5~86.3) 안이라 회귀 판정 기준으로 쓸 수 있다.

쉬움을 다시 어렵게 만들어야 할 일이 생기면 손댈 곳은 `gk: 0.55` 와
`react: 0.50` 이다 — 쉬움 실점이 1.40 으로 보통(1.99), 어려움(3.57)과
차이가 크다.

### 기존 목표는 표본이 부족했다

문서에 적힌 73/53/23% 는 **난이도당 30경기**로 튜닝된 값이다.
30경기의 95% 신뢰구간은 ±18%p 다. 실제 81.5% 인 값이 30경기에서 73% 로
나오는 것은 전혀 이상하지 않다.

이 프로젝트에서 실제로 겪은 일이기도 하다 — 같은 스크립트로 3경기만
돌렸을 때 보통 난이도가 0%(3전 3패)로 나왔다. 200경기에서는 57.0% 였다.

**밸런스를 바꿀 때는 200경기 이상을 쓴다.**

### 봇은 사람의 하한이다 — 중요

측정 봇은 `aiPlayer` 를 그대로 쓴다. 공을 향해 달리고, 골문 근처면 슛하고,
아니면 전진 패스한다. **사람은 이보다 잘한다** — 상대 위치를 보고, 공간을
읽고, 슛 타이밍을 고른다.

따라서 이 숫자는 **사람 승률의 하한**이다. 실제 사람의 승률은 이보다 높다.

그래서 이 도구는 이렇게 쓴다.

| 용도 | 적합 |
|---|---|
| 변경 전후 비교 (회귀 감지) | **적합.** 시드 고정이라 같은 조건에서 재현된다 |
| 사람 승률의 절대값 예측 | **부적합.** 하한만 준다 |

절대 난이도는 결국 **사람이 직접 플레이해서** 맞춘다. 시뮬레이션은 그
조정이 다른 난이도를 망가뜨리지 않았는지 확인하는 데 쓴다.

## 재측정 시점

`roadmap.md` 의 각 단계가 끝날 때마다 같은 조건으로 다시 돌린다.
앞 단계가 승률을 바꿔놓기 때문이다.

특히 1단계(공 소유·태클)는 공 경합 방식 자체를 바꾸므로 이 표의 모든
숫자가 무효가 된다.

## 계획된 측정

### `speed` 계단 함수가 아직 유효한가

문서에 기록된 사실 — `speed` 는 AI 가 공 경합을 이기는 임계점이 `0.87`
근처에 있어 `0.86 → 0.88` 만 바꿔도 승률이 67% → 27% 로 튀었다.

1단계에서 태클과 소유 경합이 들어오면 공 경합이 순수 속도 대결이 아니게
된다. **계단이 완만해질 가능성이 있다.**

측정 방법: `speed` 를 0.84~0.94 를 0.01 간격으로 두고 각 200경기.
1단계 구현 전후로 한 번씩 돌려 비교한다.

이 결과가 `team-tactics.md` 의 「난이도와 팀 강함의 축 분리」 결정에
직접 들어간다 — 계단이 남아 있으면 속도를 능력치로 옮기는 순간 팀 강함도
계단이 된다.

## 도구 사용법

```bash
node tools/soccer-sim.js              # 난이도당 30경기 (빠른 확인용)
node tools/soccer-sim.js -n 200       # 밸런스 변경 시
node tools/soccer-sim.js -l 1 -n 200  # 보통만
node tools/soccer-sim.js --seed 7     # 다른 시드로 재확인
node tools/soccer-sim.js --bot 2      # 사람 자리 봇을 어려움 수준으로
```

`--seed` 를 바꿔 결과가 크게 흔들리면 표본이 부족한 것이다.
