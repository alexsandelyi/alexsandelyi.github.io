# 팀·전술·선수 상성

**상태: 전부 제안.** 미측정.

여기서 "양 팀이 동일하다" 는 전제가 사라진다.
**이 단계 후 밸런스 전면 재측정이 필요하다** — 난이도 파라미터의 의미가
바뀌기 때문이다.

## 선수 능력치

5개로 제한한다. 많으면 튜닝이 불가능해지고 플레이어도 못 읽는다.

| 능력치 | 영향 |
|---|---|
| 속도 | `P_MAX` 배수 |
| 슛 | 슛 속도, 조준 오차 |
| 패스 | 패스 정확도, 스루패스 성공률 |
| 수비 | 태클 성공률, 소유 경합 |
| 체력 | 스프린트 지속, 후반 페이스 저하 |

골키퍼는 `선방` 하나를 더 갖는다 (`reach` 배수와 `gkTarget` 반응 계수).

값은 1~99 로 두되 **화면에는 5단계 막대로만 보여준다.** 숫자를 그대로
노출하면 플레이어가 최적화 게임을 하게 되고, 이 게임의 관심사가 아니다.

## 포메이션

`FORMATION` 상수를 테이블로 바꾼다.

- 4-4-2 (현행)
- 4-3-3
- 3-5-2
- 5-3-2

각 포메이션은 정규화 좌표 배열 + 역할(GK/DF/MF/FW)만 갖는다.
현재 구조가 이미 정규화 좌표(`hx`, `hy`)라 확장이 자연스럽다.

## 전술

**현재 `slotTarget()` 의 상수들이 그대로 전술 슬라이더가 된다.**
새 개념을 발명할 필요가 없다.

| 전술 | 현재 상수 | 범위(제안) |
|---|---|---|
| 수비 라인 높이 | `DF` 클램프 `FW * 0.58` | 0.45 ~ 0.70 |
| 압박 강도 | `shiftX = 0.42` | 0.25 ~ 0.55 |
| 폭 | `shiftY = 0.30` | 0.20 ~ 0.45 |
| 추격 인원 | 최근접 1명 고정 | 1 ~ 2명 |

## 상성

전술 간 가위바위보를 만든다. 이것이 "상성" 의 실체다.

| 강점 | 약점 |
|---|---|
| **높은 수비 라인** — 중원 지배 | 배후 공간. 상대 FW 속도가 높으면 역습에 취약 |
| **강한 압박** — 공을 빨리 뺏음 | 대형이 벌어짐. 상대 패스가 높으면 통과당함 |
| **좁은 폭** — 중앙 차단 | 측면. 코너·크로스에 약함 |

각 상성은 **이미 있는 물리로 자연히 발생**해야 한다.
별도 보정 계수를 곱해 인위적으로 만들지 않는다. 발생하지 않으면
시뮬레이션으로 확인하고 상수 범위를 조정한다.

측정 방법: 전술 조합별로 봇 대 봇 30경기씩 돌려 승률 행렬을 만든다.
가위바위보가 성립하면 각 전술이 최소 하나의 다른 전술에 우위를 가져야
한다.

## 팀

동네 축구 정체성에 맞는 팀 8~12개. 팀마다 포메이션 선호, 전술 성향,
능력치 분포가 다르다.

**팀 종합 등급은 선수 능력치에서 파생시킨다.** 직접 입력하지 않는다 —
표시 등급과 실제 강함이 어긋나면 디버깅이 불가능해진다.

## 난이도와 팀 강함의 축 분리

**미결이지만 제안은 분명하다.**

난이도(`LEVELS`)와 팀 강함이 둘 다 있으면 중복이다. 축을 분리한다.

| 축 | 담당 | 파라미터 |
|---|---|---|
| 난이도 | 상대 AI 의 반응·판단 | `react`, `aimErr`, `gk` |
| 팀 | 선수의 물리적 능력 | 능력치 5개 |

`speed` 는 난이도에서 빼고 선수 속도 능력치로 이관한다.

이렇게 하면 "어려움 난이도 + 약팀" 같은 조합이 성립하고, 두 축이 서로를
가리지 않는다. 대신 **목표 승률 80/53/23% 가 단일 목표로는 성립하지
않게 된다** — `roadmap.md` 미결 항목 참조.

## 검증 기준

- 팀 등급차가 승률에 단조 반영된다 (강팀일수록 이긴다).
- 상성 행렬에서 가위바위보가 관찰된다.
- 포메이션 4종 모두에서 선수가 겹치거나 한쪽에 몰리지 않는다.
- 능력치를 전부 동일하게 두면 현행 밸런스가 재현된다 (회귀 확인).
