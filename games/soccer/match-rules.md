# 경기 규칙과 심판

**상태: 3단계 구현·측정 완료.**

새 상태 기계가 필요한 단계다. `baseline.md` 에 적었듯 현재 `state` 는
`title | play | goal | end` 뿐이다. 여기에 `setpiece` 를 더한다.

## 아웃오브플레이

터치라인의 벽 반사를 제거하고, 공이 선을 넘으면 **마지막 터치한 팀**을
근거로 재개 방식을 정한다.

| 넘은 선 | 마지막 터치 | 재개 |
|---|---|---|
| 사이드라인 | 어느 쪽이든 | 스로인 (반대 팀) |
| 골라인 | 공격 팀 | 골킥 |
| 골라인 | 수비 팀 | 코너킥 |

`collide()`와 킥에서 `ball.lastTouch = p`를 기록한다.
오프사이드와 파울도 이 값을 쓴다.

골문 안으로 들어가는 경우(`inGoalMouth`)는 기존대로 득점이 우선한다.

## 세트피스 상태 기계

스로인·골킥·코너킥·프리킥·킥오프·PK 를 **하나의 흐름**으로 처리한다.

```
setpiece {
  type,   // throw | goalkick | corner | free | kickoff | penalty
  side,   // 차는 팀
  spot,   // {x, y} 공 고정 위치
  taker,  // 차는 선수
  timer   // 자동 진행까지 남은 시간
}
```

흐름:

```
공을 spot 에 고정
  → 상대 선수를 spot 에서 9.15m(=183단위) 밖으로 밀어냄
  → taker 를 공 옆으로 이동
  → 플레이어 팀이면 조준 입력 대기 (최대 3초, 초과 시 자동)
    AI 팀이면 짧은 지연 후 자동
  → 차면 state = 'play'
```

`resetPositions()` 를 킥오프 전용에서 세트피스 배치 함수로 일반화한다.

### 대기 시간

`principles.md` 4번(아케이드 우선) 적용. 세트피스는 게임을 멈추므로
짧게 잡는다.

| 종류 | 대기 |
|---|---|
| 스로인 | 0.8초 |
| 골킥 | 1.0초 |
| 코너킥 | 1.5초 |
| 프리킥 | 1.5초 |
| PK | 2.0초 |

스로인 연쇄를 막기 위해 스로인 때 터치라인 근처 선수는 안쪽으로
재배치한다. 상대는 재개 지점에서 9.15m 밖으로 밀어낸다.

## 오프사이드

**도입하되 난이도에 연동한다.**

아케이드 게임에서 오프사이드는 플레이어가 이유를 모른 채 공격이 무산되는
최대 원인이다. 그래서 조건부로 넣는다.

- **판정 시점:** 패스를 차는 순간. 받는 선수가 뒤에서 두 번째 수비수보다
  앞이고 공보다 앞이면 표시해 두고, 그 선수가 공을 잡으면 프리킥.
- **시각 피드백 필수.** 판정 시 오프사이드 라인을 잠깐 그린다.
- **난이도별:** 쉬움 = 끄기 / 보통 = 켜기 / 어려움 = 켜기.

`slotTarget()`은 평소 라인 초과 이동을 보통 72%, 어려움 90% 되돌린다.
공을 소유한 동안 FW는 4초마다 교대로 라인을 돌파하며, 어려움은 보통보다
절반만 침투한다. AI가 라인을 대체로 지키되 일부 침투 위험을 남기므로 실제
경기에서도 판정이 발생한다. 후보가 아닌 동료가 정상 수신하면 이전 후보를
해제한다.

## 경기 진행

### 전·후반제 — 구현됨

180초 단판 → 90초 × 2, 하프타임에 **코트 체인지**.

`baseline.md` 에 적었듯 `side === 0` 을 방향으로 쓰는 코드가
`homePos`, `aimAt`, `gkTarget`, `passTarget`, 색상 배정에 흩어져 있다.

깔끔한 방법은 팀별 `attackDir` 필드(`+1` / `-1`)를 두고 모든 방향 계산을
그리로 돌리는 것이다. 색상은 방향과 분리해 팀 정체성으로 남긴다.

### 경기 길이 — 구현됨

설정에서 고른다: 3분 / 6분 / 10분. 기본 3분(현행 유지).

### 추가시간 — 구현됨

세트피스와 득점 정지 시간을 누적해 각 반 끝에 더한다.

## 파울과 카드

태클(`input-system.md`)이 들어온 뒤에 성립한다.

- 태클이 공보다 **선수를 먼저** 맞히면 파울 → 프리킥.
  페널티 에어리어 안이면 PK.
- 속도·각도로 심각도를 매긴다: 무경고 / 옐로 / 레드.

옐로카드까지만 구현했다. 레드(퇴장)는 인원 가변 처리라
11명 고정 배열을 쓰는 `FORMATION` 전반에 파급된다.
`team-tactics.md` 의 포메이션 테이블화 이후로 미룬다.

옐로카드와 체력은 경기 전체 상태다. 득점 후 킥오프와 하프타임의 위치
재배치에서는 유지하고, 다음 경기를 시작해 선수 배열을 다시 만들 때만
초기화한다.

## 넣지 않을 것

명시적으로 제외한다 — `principles.md` 4번에 반한다.

- VAR, 부상, 날씨, 심판 성향
- 골키퍼 백패스 규칙, 6초 규칙
- 교체 (필요해지면 `game-modes.md` 시즌 모드에서 다룬다)

## 검증 기준

- 아웃 판정 후 재개까지 흐름이 끊긴 느낌이 없다.
- 세트피스에서 선수가 겹치거나 경기장 밖으로 나가지 않는다.
- 코트 체인지 후 양 팀이 올바른 골문을 공격한다.
- 쉬움은 오프사이드 0회, 보통·어려움은 경기당 0회 초과 3회 이하.
- 경기당 총 득점이 `principles.md` 의 목표 범위 안
  (현실 계측치 전환으로 3분 5~6골 → 10분 2~3골로 바뀌었다).
- `node tools/soccer-sim.js --self-test`의 오프사이드·파울·옐로 검사 통과.
