# 일빵 — 게임 런처

K-컬처 AI 빌더 게임 런처 UI. 정적 사이트 한 장으로 동작한다.

**https://alexsandelyi.github.io/**

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 앱 전체 (React + 디자인 시스템이 파일 안에 번들되어 있음) |

## 레이아웃

창 크기를 따라가는 반응형이다. 브레이크포인트는 두 개.

- **1024px 이상** — 좌측 아이콘 레일 + 히어로 2단. 읽는 영역은 최대 1440px 로 묶고 배경·레일·탭바는 창을 꽉 채운다.
- **1023px 이하** — 히어로 세로 스택, 카드 레일 줄바꿈
- **767px 이하** — 좌측 레일이 하단 탭바로 전환, 로고는 상단바로 이동

폰트는 시스템 한글 폰트(Apple SD Gothic Neo / 맑은 고딕)를 쓴다.

## 게임: 동네 축구 (`games/soccer/`)

**https://alexsandelyi.github.io/games/soccer/**

골키퍼 포함 **11명 대 11명**. 라이브러리 없는 Canvas 2D 한 파일(32KB).
런처 번들과 완전히 분리돼 있어 `index.html` 이 재생성돼도 영향받지 않는다.

- 공에 가장 가까운 우리 선수가 자동으로 잡힌다(흰 테두리 + 삼각 표시).
  두 선수가 비슷할 때 깜빡이지 않게 90단위 히스테리시스를 뒀다.
- 조작 — PC: `WASD`/방향키 이동, `스페이스` 슛, `왼쪽 Shift` 패스
  (2P는 `IJKL` + `엔터` + `오른쪽 Shift`)
  모바일: 화면을 끌면 그 지점이 조이스틱 중심, 우하단 `슛`·`패스` 버튼
- 경기 3분, 난이도 3단계. 전적은 난이도별로 `localStorage` 에 남는다
  (정적 호스팅이라 서버 랭킹은 불가)

### 좌표계와 화면

경기장은 실제 규격 **105m × 68m** 를 1m = 20단위로 옮긴 2100×1360 이다.
페널티박스·골에어리어·센터서클·페널티마크 치수도 실측값이다. 골문만
7.32m(=146) 에서 300 으로 넓혔다 — 골키퍼가 있는 상태에서 실측대로 두면
득점이 거의 안 난다.

물리·AI 는 항상 이 논리 좌표로 계산하고, 화면 크기·회전은 그리기와 입력
변환에서만 반영한다. 창 크기가 경기 결과를 바꾸지 않게 하려는 것이다.

줌은 고정하지 않는다. 화면이 커서 경기장 전체가 담기면 그대로 보여주고
(미니맵도 숨긴다), 작으면 선수 지름 26px 를 하한으로 두고 카메라가 공을
따라간다. 세로 화면에서는 경기장을 90° 돌려 세로로 쓴다.

### 밸런스 (시뮬레이션으로 튜닝)

사람 수준 봇으로 자동 대전시켜 값을 골랐다. 측정 도구는
`tools/soccer-sim.js` — `readHuman` 만 봇으로 갈아끼우고 실제 `step(1/60)`
을 반복한다.

난이도당 **200경기** 실측 (2026-07-31, seed 1):

| 난이도 | 승률 (95% CI) | 경기당 총 득점 |
|---|---|---|
| 쉬움 | 81.5% (75.5~86.3) | 5.47 |
| 보통 | 57.0% (50.1~63.7) | 4.62 |
| 어려움 | 23.5% (18.2~29.8) | 5.62 |

전체 경기당 총 득점 5.24. 목표(80 / 53 / 23%, 5~6골) 안에 있다.

**30경기로는 판정할 수 없다.** 95% 신뢰구간이 ±18%p 라 난이도 간 차이가
묻힌다. 같은 스크립트로 3경기만 돌렸을 때 보통 난이도가 0%(3전 3패)로
나왔고, 200경기에서는 57.0% 였다.

측정으로 드러난 두 가지:

- **골키퍼에게 다이빙 리치(몸 반지름의 1.9배)를 주는 것이 결정적**이었다.
  이게 없으면 골문을 실측(146)까지 좁혀도 경기당 7골이 넘었다. 리치를 주니
  9골 → 5골로 떨어지고 평균 스코어가 2~3 : 2 가 됐다.
- **AI `speed` 는 계단 함수처럼 작동한다.** AI 가 공 경합을 이기는 임계점이
  0.87 근처라 0.86→0.88 만 바꿔도 승률이 67%→27% 로 튀었다. 그래서 speed 는
  0.86~0.92 로 좁게 두고, 난이도 차이는 반응 지연·조준 오차·골키퍼 반응으로
  만든다.
