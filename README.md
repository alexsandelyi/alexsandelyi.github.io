# 일빵 — 게임 런처

K-컬처 AI 빌더 게임 런처 UI. 정적 사이트 한 장으로 동작한다.

**https://alexsandelyi.github.io/**

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 앱 전체 (React + 디자인 시스템이 파일 안에 번들되어 있음) |
| `assets/clickable-v2/` | 버튼 플레이트 이미지 8개 |
| `assets/lettering-v1/` | 섹션 제목 레터링 3개 |
| `app-ads.txt` | AdMob 광고 인증. **도메인 루트에 있어야 하므로 지우면 안 된다** |

`index.html` 은 자립형이 **아니다** — 위 이미지 11개를 상대경로로 참조하므로 함께 배포해야 한다.

## 수정 방법

작업 원본은 `일빵-런처-확정안.html`(git 추적 제외)이다. 고친 뒤 복사해서 배포한다.

```bash
cp 일빵-런처-확정안.html index.html
```

## 레이아웃

창 크기를 따라가는 반응형이다. 브레이크포인트는 두 개.

- **1024px 이상** — 좌측 아이콘 레일 + 히어로 2단. 읽는 영역은 최대 1440px 로 묶고 배경·레일·탭바는 창을 꽉 채운다.
- **1023px 이하** — 히어로 세로 스택, 카드 레일 줄바꿈
- **767px 이하** — 좌측 레일이 하단 탭바로 전환, 로고는 상단바로 이동

폰트는 시스템 한글 폰트(Apple SD Gothic Neo / 맑은 고딕)를 쓴다.
